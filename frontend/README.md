# یدکی‌یار — رابط کاربری (React + Vite + TypeScript)

راست‌چین کامل، **تقویم شمسی** در همه‌جا، بدون گرادیانت. زبان بصری «تابلوی جاده»؛ فونت‌ها محلی‌اند (بدون CDN).

## اجرا
```bash
npm install
npm run dev          # نیاز به بکند روی پورت ۳۰۰۰ (پروکسی /api)
npm run dev:mock     # پیش‌نمایش بدون بکند با داده‌ی نمونه (ورود: 09120000000 / demo1234)
npm run build
```
متغیرها: `.env.example`. برای استقرار، `dist/` را با Nginx سرو کنید و `/api` را به بکند پروکسی کنید (مسیر `/pay/:token` عمومی است و باید از اینترنت در دسترس باشد).

## صفحه‌ها و قابلیت‌ها
میز کار | فروش (فاکتور، پیش‌فاکتور، برگشتی‌ها؛ صندوق سریع، چاپ A5، دریافت، لغو، **ارسال به مودیان**، **پیامک**، **لینک پرداخت آنلاین**) |
کالاها (جستجو، سازگاری، جایگزین، **ورود/خروج اکسل و CSV**، **چاپ برچسب بارکد**، شناسه کالا/خدمت) | انبار | خرید | طرف‌حساب‌ها (**یادآوری بدهی با پیامک**) |
دریافت و پرداخت | هزینه‌ها | چک‌ها | گزارش‌ها (سود خالص) | اطلاعات پایه | تنظیمات (کاربران، گزارش فعالیت، **مودیان، پیامک، درگاه**) |
صفحه‌ی عمومی پرداخت مشتری (`/pay/:token`).

میان‌بر: `Ctrl+K` جستجوی سراسری کالا.

## نکات
- تاریخ‌ها در API میلادی و در رابط شمسی‌اند (`src/lib/jalali.ts`).
- واحد پول: ریال (`CURRENCY` در `src/lib/format.ts`).
- `src/lib/calc.ts` همان الگوریتم بکند است تا پیش‌نمایش و مقدار ثبت‌شده یکی باشد.
- ورود اکسل با `read-excel-file` و خروجی با `write-excel-file` (فقط `.xlsx`؛ فایل قدیمی `.xls` را به xlsx یا CSV ذخیره کنید). برچسب‌ها با `jsbarcode` (Code128: فقط حروف انگلیسی و عدد).
- حالت mock فقط برای پیش‌نمایش است؛ داده‌ها در حافظه‌اند و با رفرش به حالت اول برمی‌گردند.
